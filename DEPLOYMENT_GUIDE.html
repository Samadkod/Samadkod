❓Questions fréquentes

Que faire si Streamlit Cloud dit "Repository not found" ? +
Vérifiez que votre dépôt GitHub est public et que vous êtes connecté avec le bon compte. Si le repo est privé, rendez-le public ou donnez accès à votre compte GitHub à Streamlit Cloud.
Combien de temps pour que l'app soit en ligne ? +
En général 2-3 minutes. Streamlit installe les dépendances, build l'app, et vous génère une URL. Vous verrez une barre de progression en temps réel.
Est-ce que c'est gratuit ? +
✅ Oui, Streamlit Community Cloud est gratuit. Vous avez un limite d'une app gratuite au départ, puis vous pouvez acheter des "credits" pour plus d'apps, mais c'est sans risque pour tester.
Mes données sont-elles sauvegardées sur l'app en ligne ? +
Non. Les données sont synthétiques et régénérées à chaque chargement. Seul le CSV/Excel que vous exportez manuellement est conservé sur votre machine.
Puis-je modifier l'app après le déploiement ? +
Oui. Modifiez le code sur GitHub, commitez, et Streamlit Cloud redéploie automatiquement la version la plus récente (~1-2 min). Testez toujours en local d'abord.
